WEEK 8 FINAL PROJECT: PERSONAL MINI-TOOLKIT PLAN

TOOLS
1. To-Do List: Lets the user add, view, and remove tasks while the program is running.
   Concepts: while loop, if/elif/else, changing list (append and pop), for loop, enumerate, f-strings, input validation.

2. Simple Calculator: Performs addition, subtraction, multiplication, or division on two numbers.
   Concepts: conditionals, try/except, input, f-strings, arithmetic, division-by-zero check.

3. Number Guessing Game: Asks the user to guess a randomly selected number from 1 to 10 until they get it right.
   Concepts: while loop, conditionals, random number, counter, try/except, f-strings.

PROGRAM FLOW
The main while loop shows the menu repeatedly. if/elif/else routes each choice to its tool or quits. Each tool returns to the main menu when it finishes. Invalid input is handled with a friendly message rather than crashing.
